## Purpose

Use this standard to configure an Extreme 5320-48P-8XE Managed POE switch for the client. It covers initial setup, management access, time, VLANs, ports, monitoring, labels, configuration backup, MFA access, validation, and documentation updates.

<Warning>
  This branch contains demonstration values. Confirm each value against the client overview and current network records before you use a command on a switch.
</Warning>

## Procedure

1. Confirm the approved client values and network design.
2. Register the switch and confirm the required firmware.
3. Complete the initial console setup.
4. Configure management, secure access, time, VLANs, and ports.
5. Configure the applicable monitoring and backup services.
6. Label the switch and cables.
7. Validate the configuration and record evidence.
8. Update the client overview, network diagram, port map, and implementation record.

## Work Instruction

### 1. Confirm the source records

Review the client overview, IP address list, LAN-WAN diagram, switch port map, rack diagram, BankXDR design, and change approval. Stop if an address is in use or if two sources give different values.

### 2. Register the switch and confirm firmware

Sign in to the Extreme support portal with the account in Definitions. Register the serial number. Confirm support coverage and the approved Switch Engine firmware path.

### 3. Complete initial console setup

Connect by serial console. Press **Enter** to start the setup sequence.

1. Select Switch Engine unless the approved design requires Fabric Engine.
2. Keep MSTP disabled unless the network design requires it.
3. Enable enhanced security mode.
4. Create the approved administrative and failsafe accounts. Refer to the password source in Definitions.
5. Permit the failsafe account for network access only when the support standard requires it.

```bash Failsafe account
configure failsafe-account permit all
save config
```

Restart the switch and sign in with the approved administrative account.

### 4. Configure management and secure access

Run the following commands with the values in Definitions.

```bash Management and secure access
disable dhcp vlan default
configure vlan default ipaddress {{switch-management-cidr}}
configure iproute add default {{switch-default-gateway}} vr VR-Default
configure snmp sysName {{switch-system-name}}
enable ssh2
configure ssh2 secure-mode on
save config
```

Reconnect by SSH to the management address in Definitions. Confirm that the prompt shows the defined system name.

### 5. Configure time

```bash Time
enable ntp
configure ntp server add {{ntp-server}}
configure timezone name EST -300 autodst name EDT begins every second sunday march at 2 00 ends every first sunday november at 2 00
configure ntp local-clock none
save config
```

### 6. Configure VLANs and ports

Create each VLAN in the VLAN and port definitions table. Add the listed access ports as untagged and the listed uplink ports as tagged. Do not create a VLAN that the approved client design excludes.

```bash VLANs and ports
create vlan WLAN-MGMT tag 11
configure vlan WLAN-MGMT add ports 5-8 untagged
configure vlan WLAN-MGMT add ports 47-48 tagged

create vlan VOICE tag 20
configure vlan VOICE add ports 9-12 untagged
configure vlan VOICE add ports 47-48 tagged

create vlan NVR tag 30
configure vlan NVR add ports 13-16 untagged
configure vlan NVR add ports 47-48 tagged

create vlan CORE tag 40
configure vlan CORE add ports 47-48 tagged
save config
```

Add a clear description to each connected port. Use the device or circuit name. Keep the first character alphanumeric.

```bash Port description example
configure ports 1 description-string "RTR-NORTH-01 GE0/0/0"
save config
```

### 7. Configure monitoring

**Applicable path:** {{switch-monitoring-design}}

This switch uses standalone XDR monitoring. Configure direct syslog forwarding to the collector in Definitions.

```bash Syslog
configure syslog add {{syslog-collector}} vr VR-Default local0
enable syslog
save config
```

Enable node alias for operational visibility.

```bash Node alias
enable nodealias ports all
save config
```

### 8. Configure backup and administrative access

Add the switch to the backup method in Definitions. Run a backup and confirm that the job completes. Configure RADIUS MFA for normal administrative access when MFA is enabled in the client overview. Keep the approved local failsafe account for recovery.
