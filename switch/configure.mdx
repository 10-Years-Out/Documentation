## Complete initial setup

<Steps titleSize="h2">
  <Step title="Connect by serial console">
    Open PuTTY or an equivalent terminal with the approved serial settings. Press **Enter** to start the setup sequence.
  </Step>
  <Step title="Answer the platform prompts">
    Keep the switch on Switch Engine unless the approved design requires Fabric Engine. Keep MSTP disabled during this branch-switch baseline unless the network design states otherwise.

    Enable enhanced security mode. Create the approved administrative account and failsafe account. Refer to the established password source; do not copy a password into the implementation document.
  </Step>
  <Step title="Permit the failsafe account where approved">
    If the support standard requires network access for the failsafe account, run:

    ```bash failsafe-access.cli
    configure failsafe-account permit all
    save config
    ```
  </Step>
  <Step title="Restart and sign in">
    Save the configuration, restart the switch, and sign in with the newly created administrative account.
  </Step>
</Steps>

## Configure management and secure access

```bash management-and-identity.cli {2-4}
disable dhcp vlan default
configure vlan default ipaddress 192.0.2.10/24
configure iproute add default 192.0.2.1 vr VR-Default
configure snmp sysName 5320-48P-8XE-NORTH-01
enable ssh2
configure ssh2 secure-mode on
save config
```

<Check>
  Reconnect by SSH to <code>{profile.switch.management.address}</code>. Confirm that the prompt identifies <code>{profile.switch.systemName}</code> before you continue.
</Check>

## Configure time

```bash time-service.cli
enable ntp
configure ntp server add 192.0.2.20
configure timezone name EST -300 autodst name EDT begins every second sunday march at 2 00 ends every first sunday november at 2 00
configure ntp local-clock none
save config
```

## Configure VLANs and ports

<CodeGroup>

```bash Create a VLAN
create vlan WLAN-MGMT tag 11
```

```bash Add an access port
configure vlan WLAN-MGMT add port 5
```

```bash Add a tagged uplink
configure vlan WLAN-MGMT add port 48 tagged
```

</CodeGroup>

<Steps>
  <Step title="Create each required VLAN">
    Use the approved name and tag. Do not create a template VLAN that the client design excludes.
  </Step>
  <Step title="Assign access ports">
    Add each endpoint port as untagged to one intended data VLAN. Confirm how voice tagging works before you add a voice VLAN.
  </Step>
  <Step title="Assign uplinks">
    Add the required VLANs as tagged on the approved uplink ports. The source template recommends starting uplinks at port 48, but the current port map controls.
  </Step>
  <Step title="Describe the ports">
    Use clear device or circuit names. Avoid reserved characters and keep the first character alphanumeric.

    ```bash port-description.cli
    configure ports 1 description-string "RTR-NORTH-01 GE0/0/0"
    save config
    ```
  </Step>
</Steps>

## Enable useful operational data

```bash node-alias.cli
enable nodealias ports all
save config
```

Node alias improves MAC-to-IP resolution for monitoring and troubleshooting.
