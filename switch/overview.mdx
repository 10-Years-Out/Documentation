## Intended outcome

When you finish this workflow, the switch has:

- An approved system name, management address, route, and secure SSH configuration.
- The required VLANs, tagged uplinks, untagged access ports, and port descriptions.
- The applicable monitoring path: NAC-managed onboarding or standalone XDR syslog.
- A saved and verified configuration, a current backup, and updated implementation records.

## Source review

The prototype uses the current standards template, **Extreme 5320-48P-8XE Managed POE Switch Configuration, revision 1.2**, dated August 20, 2026. The original document is seven pages and combines definitions, procedure scope, work instructions, optional author notes, images, and revision history.

The web version keeps the technical intent but changes the reading model:

  <Card title="Improve" icon="arrow-trend-up">
