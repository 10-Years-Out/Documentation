## What happens when a switch is replaced

<Steps>
  <Step title="Keep the logical role">
    Leave `northAccess1` in place so procedures and cross-references still point to the branch access-switch role.
  </Step>
  <Step title="Replace the installed-asset fields">
    Update the model, system name when required, management assignment, serial number, MAC address, location, monitoring path, and backup method from the approved records.
  </Step>
  <Step title="Rebuild and review">
    Mintlify rebuilds every page that imports `profile`. Review the generated commands, implementation pages, inventory, and validation evidence in one preview deployment.
  </Step>
</Steps>

<Check>
  The replacement is documented consistently when this overview, the configuration builder, the switch standard, and the client records all show the same installed asset.
</Check>

## Authoring contract

```jsx snippets/switch-profile.mdx
export const profile = {
  services: { ntpServer: "192.0.2.20" },
  switch: {
    key: "northAccess1",
    role: "North Branch primary access switch",
    systemName: "5320-48P-8XE-NORTH-01",
    management: { address: "192.0.2.10", prefixLength: "24" }
  }
};
```
