### Intent

The purpose of this policy is to establish a standard for allowing remote access to HSLC networks.

### Scope

The scope of this policy includes all remote network access methods.

### Policy

- Remote access to HSLC networks is prohibited unless approved by the ITSC.

- Prior to activating remote access for an approved user, the user may complete training on safely and securely using the remote access.

- Remote access will be disabled by default and only enabled for approved users when necessary and for limited time.

- Whenever possible, the bank shall enforce multifactor authentication for all remote access users.

- The following are exceptions to the remote access policy. For more information on the configuration and remote access users, see the Information Security Program Documentation (ISPD).

  - Occasional vendor support that is enabled by the bank at time of support and then closed.

  - Other policies for exceptions such as: OWA, the intranet portal, and synchronized portable devices are described in the Remote and Synchronized Access Policy and recorded using forms in the Appendix of the Acceptable Use Policy.

- Remote access for employees and service providers will be monitored via weekly remote access reports received from the firewall's reporting appliance as well as daily log reviews by the IT department.

  - If any unauthorized or excessive failed logins are identified, the remote access service on the firewall will be immediately disabled.

### Compliance

The IT department will monitor all access via ports and protocols to safeguard against intrusion through applicable access points. The ITSC will periodically be provided with reports showing low, medium, and high risks.
