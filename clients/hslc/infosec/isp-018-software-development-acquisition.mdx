### Intent

The purpose of this policy is to ensure that all software is suitable for intended use and of acceptable quality based on need, cost, and compatibility.

### Scope

This policy applies to any software purchases that would involve confidential data.

### Policy

Prior to the development or acquisition of any software that affects the network, the IT department will review the following criteria:

- Hardware Compatibility

  - Microcomputer
  - Memory
  - Disks
  - Printer
  - Other peripherals

- Software Compatibility

  - Operating environment
  - Additional software requirements
  - Integration with external authentication and authorization systems (Windows domain)

- Software Features

  - Capabilities
  - Stability of current release
  - Ease of use
  - Customization capabilities (e.g., installation, screen mode, level, defaults, output)
  - Support for multiple levels of user access rights
  - Logging and reporting capabilities
  - Access to confidential data
  - Secure storage of confidential data
  - Online help
  - Ability to support incident detection based on security requirements

- Training and documentation

- Vendor Relations

  - Fee structure
  - Copy protection
  - Warranty
  - Maintenance
  - New releases
  - Technical Support
  - Security development methods

### Compliance

The ITSC will ensure all software conforms to the Information Security Policy and industry best practices.
