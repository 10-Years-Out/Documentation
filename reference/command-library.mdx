Use these patterns as a reference after you confirm the values and syntax for the installed ExtremeXOS version.

<AccordionGroup>
  <Accordion title="Management address and route" icon="route">
    ```bash
    disable dhcp vlan default
    configure vlan default ipaddress <management-address>/<prefix-length>
    configure iproute add default <gateway> vr VR-Default
    save config
    ```

    `VR-Default` is the default <Tooltip tip="Virtual router">VR</Tooltip> in the source standard.
  </Accordion>
  <Accordion title="System identity and secure SSH" icon="key">
    ```bash
    configure snmp sysName <system-name>
    enable ssh2
    configure ssh2 secure-mode on
    save config
    ```
  </Accordion>
  <Accordion title="NTP and timezone" icon="clock">
    ```bash
    enable ntp
    configure ntp server add <ntp-server>
    configure timezone name EST -300 autodst name EDT begins every second sunday march at 2 00 ends every first sunday november at 2 00
    configure ntp local-clock none
    save config
    ```
  </Accordion>
  <Accordion title="Standalone XDR syslog" icon="satellite-dish">
    ```bash
    configure syslog add <syslog-collector> vr VR-Default local0
    enable syslog
    save config
    ```

    <Warning>
      Use this block only for the direct standalone-switch path. Do not add it to a NAC-managed implementation without an approved design change.
    </Warning>
  </Accordion>
  <Accordion title="Node alias" icon="diagram-project">
    ```bash
    enable nodealias ports all
    show nodealias ports all
    save config
    ```
  </Accordion>
  <Accordion title="Save and restart" icon="power-off">
    ```bash
    save config
    reboot
    ```

    <Note>
      A restart interrupts connected devices. Confirm the maintenance window and path redundancy before you run `reboot` on a live switch.
    </Note>
  </Accordion>
</AccordionGroup>

## VLAN patterns

<CodeGroup>

```bash Create
create vlan <vlan-name> tag <vlan-id>
```

```bash Untagged access
configure vlan <vlan-name> add port <port-number>
```

```bash Tagged uplink
configure vlan <vlan-name> add port <port-number> tagged
```

</CodeGroup>

## Port descriptions

```bash
configure ports <port-number> description-string "<port-description>"
show ports description
save config
```

The source standard excludes `?`, quotation marks, angle brackets, colons, spaces, and `&` from some description contexts. Confirm the current device rules before you choose a naming convention.
