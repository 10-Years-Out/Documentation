## Exact configuration baseline

The following block is generated from the client overview. It records the baseline that the implementation procedure applies.

<pre className="audit-config"><code>{`# Identity and management
disable dhcp vlan default
configure vlan default ipaddress ${profile.switch.management.address}/${profile.switch.management.prefixLength}
configure iproute add default ${profile.switch.management.gateway} vr VR-Default
configure snmp sysName ${profile.switch.systemName}

# Secure access
enable ssh2
configure ssh2 secure-mode on

# Time
enable ntp
configure ntp server add ${profile.services.ntpServer}
configure ntp local-clock none

# VLANs
${profile.vlans.slice(1).map((vlan) => `create vlan ${vlan.name} tag ${vlan.id}`).join("\n")}

# Monitoring
${profile.switch.monitoring.mode === "standalone-xdr" ? `configure syslog add ${profile.switch.monitoring.collector} vr VR-Default local0\nenable syslog` : "# Monitoring is managed through NAC; follow the NAC onboarding record."}

# Operational data and persistence
enable nodealias ports all
save config`}</code></pre>

<Warning>
  This baseline does not replace a captured running configuration. Attach or reference the final device backup when the auditor needs byte-for-byte evidence of the complete configuration.
</Warning>
